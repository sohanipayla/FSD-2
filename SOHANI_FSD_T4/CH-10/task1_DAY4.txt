Example:
Consider a collection student having documents like this:
[
{_id:123433,name: "DDD",age:32},
{_id:123434,name: "BBB",age:20},
{_id:123435,name: "AAA",age:10},
]
ans:
db.createCollection("EX31");

db.EX31.insertMany([
  { "_id": 123433, "name": "DDD", "age": 32 },
  { "_id": 123434, "name": "BBB", "age": 20 },
  { "_id": 123435, "name": "AAA", "age": 10 }
]);

Do as directed:
(1) Create an index & fire a command to retrieve a document having age>15 and name is
"BBB". Stats must return values nReturned=1, docExamined=1, stage="IXSCAN". Perform required indexing.
ans:// Step 1: Create a Compound Index on name and age to optimize both fields together
db.EX31.createIndex({ name: 1, age: 1 });

// Step 2: Fire the command with explain() to verify the execution stats
db.EX31.find({ name: "BBB", age: { $gt: 15 } }).explain("executionStats");

(2) Create an index on subset of a collection having age>30. Also write a command to get a stats "IXSCAN" for age>30.
ans:
// Step 1: Create a Partial Index filtering only the subset where age > 30
db.EX31.createIndex(
  { age: 1 },
  { partialFilterExpression: { age: { $gt: 30 } } }
);

// Step 2: Fire the command to retrieve documents and check stats for age > 30
db.EX31.find({ age: { $gt: 30 } }).explain("executionStats");
